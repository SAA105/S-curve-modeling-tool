# S-curve-modeling-tool
Interactive graphical application for modeling S-shaped two-dimensional curves.  Such curves arise, for example, in the design and modeling of aircraft-engine nozzles, where the nozzle contour must satisfy specified aerodynamic conditions and geometric constraints.

## Running from Python
python S_curve_modeling.py

## Requirements
- Python 3
- NumPy
- SciPy
- Matplotlib
- Tkinter
