# S-curve-modeling-tool
Interactive graphical application for modeling S-shaped two-dimensional curves.  Such curves arise, for example, in the design and modeling of aircraft-engine nozzles, where the nozzle contour must satisfy specified aerodynamic conditions and geometric constraints.

## Files
This project contains both source code and executable file

S-curveModelingTool.py

S-curveModelingTool.exe

Due to the memory limit the executable file is stored in my OSF page: https://osf.io/swr7d/overview

## Running from Python
python S-curveModelingTool.py

## Requirements
- Python 3
- NumPy
- SciPy
- Matplotlib
- Tkinter
